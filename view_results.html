GM-VAE Results Viewer

⚠️ Important: Images generees localement

Cette visionneuse affiche les images generees localement pendant l'entrainement de vos modeles. Les images ne sont pas incluses dans le depot GitHub et doivent etre generees avec la commande ./run_*.sh.

Si vous ne voyez pas d'images, c'est normal - vous devez d'abord entrainer un modele qui generera des reconstructions dans le dossier results/.

Pour utiliser cette visionneuse:

  1. Entrainez un modele avec l'un des scripts (ex: ./run_singlegpu.sh)
  2. Executez ./view_results.sh pour ouvrir cette page dans votre navigateur
